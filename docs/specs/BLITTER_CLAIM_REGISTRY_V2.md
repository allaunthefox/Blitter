## Frozen representation boundary

Canonical U192 is `[w0,w1,w2,w3,w4,w5]`, `w0` least significant. The V1 format byte `vv l b rrrr` structurally decodes all 256 bytes but admits only version 0 with reserved bits zero: `0x00` LE/LSW, `0x10` BE-per-word/LSW, `0x20` LE-per-word/MSW, `0x30` BE/MSW. There is **no host-native, auto-detection, or generic mixed mode**; the two mixed layouts work only when explicitly tagged, normalize immediately to canonical words, and must byte-identically re-encode.

`u192-format-matrix-v1` covers the `2×2` product of limb order × byte order exactly once. B4 machinery is reused only as reversible-codec/projection-certificate architecture; projection authority never upgrades unrelated arithmetic or theorem authority.

## Authority separation

`BLITTER-ISA-V1` is the single semantic source. A semantic-profile digest binds which specification was targeted; it is **not** a conformance proof. Heartbeat is advisory. **lease/fencing has separate safety/liveness obligations**. Ratchet/environmental/RAS/ECC data is provenance/advisory unless separately sealed as input. Image identity requires registry/build evidence, not an ISA hash. Security-plugin TLS/stamps are transport/provenance evidence, not arithmetic authority.

No promotion is permitted without all required evidence, negative controls/falsifiers, independent replay at the claimed tier, and a mechanical **contract-removal** failure when required evidence is deleted or changed.
